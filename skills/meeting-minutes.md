# 会议文稿技能

为政企客户会议生成纪要、备忘与跟进文稿时使用本技能。目标：结构稳定、来源可核对、阅读负担低。

## 结构模板

会议文稿按以下骨架组织（小会议可省略空章节，但已有内容的章节顺序不变）：

1. **会议信息**：时间、地点/形式、参会方（单位+人员）、主持人、记录人。全部来自材料原文，缺项写"未提供"，不推测。
2. **议题纪要**：每个议题一节。按"客户表述 / 我方回应 / 双方确认结论"三段区分；发言归属到具体单位或人员，不合并转述。
3. **决议与跟进**：每条含责任方、时限（有具体日期写日期，只有相对时限写"材料所述时限"）、输出物。
4. **风险与待确认**：材料中出现但双方未达成一致的点；无依据的推断不进入正文，放入本节并标注"待确认"。

## 事实规则

- 金额：保留材料原文的数字与单位；上下限表述（"不超过 X 万""X 至 Y 万"）不得改成单点值。涉及"超 10 万需审批"等内部规则时只标注适用性，不改写金额。
- 统计：数量、比例必须写明统计主体与范围（"五邑中医院项目 3 个考点"而不是"3 个考点"）；跨材料汇总时列出各自出处。
- 包含关系：方案范围按材料原文表述；"含/不含""另计"不得互换。
- 意向程度：区分"表示意向 / 承诺 / 已落实"三级，按材料原文措辞对齐，不升格（"考虑"不写成"同意"，"同意"不写成"已实施"）。
- 执法/合规结论：材料没有依据的执法或合规定性一律不写；引用监管要求时注明材料出处。

## 版式规则（截图阅读宽度）

- 正文段落不超过 5 行；列表项一句话一条。
- 表格列数不超过 5；金额与时限单独成列。
- 标题层级只用两级（章节标题、条目标题），正文不加大字号。
- 用户以截图方式反馈问题时，优先检查上述三条是否导致横向溢出。

## 篇幅

默认纪要按内容自然长度，不设最低页数。仅当用户在本次对话中明确约定"详版/两页以上/完整版"时才按约定扩展；扩展以补充材料事实为限，不得为凑篇幅重复或泛化表述。
