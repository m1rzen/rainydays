# RainyDays 基础工作流交付规格

本文件保留D系列的文件、研究、文档与重复任务契约。2026-10-18用户进一步要求完整通用Agent，最终范围以[通用规格](general-agent.md)为准；本文件的40次任务和D18只构成中间里程碑。

Status: approved

日期：2026-10-18

范围：Windows本地单用户、少量熟悉同事。2026-10-18用户已批准当前D+A路线；研发入口见[手册](../agents/README.md)。

## 1. 问题与成果

同事需要把散落的文件和公开网页变成有依据的回答、可编辑的报告或表格，并把成功做过的工作再做一次。目前工程能力已经存在，用户仍可能卡在旧配置、模型额度、任务中断、输出理解或安装环境。

交付物是一套可独立安装和维护的应用、支持的模型配置说明、经验证的任务样本、使用指南、版本说明与可恢复升级方案。基础工作流不需要Node、npm、MSVC或修改JSON；扩展开发任务/第三方MCP服务器的运行依赖按通用规格单独声明。

## 3. 明确支持范围

- 系统：首发 Windows 11 x64 标准用户；具体构建、最低运行库和磁盘需求由 D13 实测后记录。其他系统、架构暂不作保证。
- 模型：先认证一套实际可用、支持流式与工具调用的配置。其他兼容地址可作为高级设置，但未测试不得标“已支持”。第二配置是后续兼容性检查，不是首发必须新写适配器。
- 资料：文本型 PDF、DOCX、XLSX、TXT/MD；含公式的 Excel 明确区分公式、缓存值和实际重算。扫描件、宏、受保护文件、极大文件明示限制，不装作完整读取。
- 研究：公开网页，一条可靠搜索路径和网页阅读。登录/验证码由用户处理；不承诺绕过或自动控制全部网站。
- 输出：新建及另存 DOCX/XLSX，基础标题、表格、链接与数值类型；不承诺原文件复杂版式无损编辑、完整 Office 桌面自动化或所有公式计算。
- 重复任务：手动触发，一份可编辑的任务模板，复用普通 Agent。首版不含定时无人值守、自动安装脚本依赖。
- 文件整理：已选目录内有限批量改名/移动；不加入自动永久删除或跨盘事务系统。
- 隐私：本地保存历史，模型调用按实际请求发送必要内容；首次配置和使用指南说明这一点。诊断默认不含正文。

## 4. 核心状态与数据语义

一次用户发送对应一次 run。同一会话的发送串行化；批准范围属于该 run。任务模板每次触发产生新 run、重新核实输入/输出，不能携带旧授权。

界面状态应能表达：待开始、执行中、等待用户/权限、正在停止、已完成、失败、已取消、被中断。完成由宿主结果与任务检查支持，不能只看模型说“完成”。已经完成的文件保留；部分成功要列出剩余项。

重启后的未知写入不自动重试；检查已落盘成果再让用户选择继续或另存。工作目录断开只影响相关工具；会话和本地成果仍可查看。

附件、来源、成果、执行状态优先从现有持久记录投影。只有当前记录无法区分这些行为时才增加最小字段或版本迁移；禁止先创建另一套调度总线、数据库和代理内核。

## 5. 架构与测试决定

复用 Agent/LLM/Memory/Session、现有授权与执行器、文档与来源回执、SQLite、Electron。详细接口和查找入口见 [架构](../agents/architecture.md)。界面保持用户已经接受的对话与成果设计；新增操作放在任务、成果和按需展开面板中。

主验证接口依次为现有 Agent + 可控本地模型服务、文件/来源/数据库公共接口、临时用户目录的真实 Electron，以及当前安装候选。真实内容质量和同事学习成本必须人工核对，不能用合成响应替代。候选接口随本规格一起供用户确认；不得新建与生产路径分离的“验收专用 Agent”。

D02实施决定（2026-10-18）：复用LLMClient的流式/非流式接口，共享结束状态和完整工具JSON检查；不新增模型路由平台。chat保留Message兼容结果并附可选usage，stream最终事件附可选usage；只作为响应元数据，下一次请求只投影对话协议字段。标准流请求启用include_usage，缺失记未知；不因兼容失败自动换请求格式重发。实际模型仍须单独认证，不能由loopback通过推断已支持。

## 6. 排除与扩展条件

明确排除Prism和钉钉。远程Worker/Relay、插件市场、双浏览器、Android、媒体生成、Anima/HUD、无限自治编队、公共云账号系统、企业审计平台不作为本版门槛。代码、CLI、MCP、单浏览器、原生Windows操作与有界子任务已由通用规格纳入必需范围，交由A系列实施。

OCR/PPTX、可编辑偏好记忆、特定业务连接器、本机定时任务仍见[扩展决策](../work/colleague-delivery/plan.md#扩展候选)。通用MCP接入与浏览器不受此后置规则限制；不按Lux工具数量补齐无关功能。

## 7. 安全与验收边界

采用 [固定安全基线](../agents/safety-budget.md)，不放宽现有核心保护以换取通过。普通产品票只验证受影响的边界；安装候选统一验证发布属性。新建复杂审计、全 SQL 插桩、逐卡身份链不在默认任务内。

真实模型的配置、任务数量与预算必须有授权。既有 default 五项授权保持原范围；深度评估、更多配置或重复收费执行不由这份规划自动授权。
