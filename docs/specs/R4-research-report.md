# R4 研究与报告

状态：approved，依据产品路线及顺序开发授权。

- 沿用一个 DuckDuckGo 搜索适配器与 fetch_markdown；搜索摘要只用于发现来源，不能计作已读网页。
- 成功读取返回实际最终 URL、标题、内容、是否截取与时间的宿主回执。失败、空内容、部分读取分别可见；页面文字无法伪造另一个已读来源。
- 从会话工具历史恢复来源清单，按当前回答涉及的读取区分状态。对回答中的网页链接标出未读取来源；这仅检查来源读取一致性，不宣称事实正确。
- Word 报告可附参考资料；提供 sources 参数时必须来自该会话实际读取的来源，生成可编辑文档与可点击链接。仍沿用 R2 新建授权。
- 安静的折叠来源区展示状态、网址与失败提示，支持复制网址；不增加外部打开的特权通道。
- 合成资料覆盖多来源、矛盾事实、失败、截取、正文伪造 Source、未知引用、重开会话及 Word 参考资料。真实模型质量另用明确批准的配置与五个脱敏任务验收。

复用现有消息持久化与结果投影，无新数据库表或联网框架。历史纯文本读取不追溯标为已读，以免从不可信正文推断回执。
