# R5 首次使用与默认能力

状态：approved，来自已批准产品路线和顺序开发指令。R5 依赖 R2；R4 的真实质量检查因模型额度阻塞，不阻止本切片工程。

## R5-01 配置与连接

首次无密钥时直接打开模型设置，保留关闭和探索能力，不强制教程。模型名称、地址、密钥在主表单；保存后用户主动检测连接。检测只向所选已保存配置发一条短消息，最多 16 输出 token、15 秒、无重试、无工具、无会话或文件上传；不改变当前配置或创建会话。明示可能产生少量费用。错误区分密钥、额度、模型、频率、超时/网络，提供下一步；不回显密钥或提供方原始错误。

常用分类只保留通用、模型配置、语音播报、语音输入；待接入分类隐藏，数据和既有保存接口保留。通用主要显示模型、工作目录、成果目录；高级身份和部门目录按需展开。尚未接入的内部运行设置保留存储，不作为可操作控件呈现。模型高级设置折叠；没有实现的 transport/proxy 等隐藏，不声称生效。

使用真实 Electron 和合成模型服务验证首次打开、保存加密凭据、连接成功/额度失败、不上传历史、一次请求、键盘分类、窄窗口与无障碍。三名新用户的实际首次任务和真实耗时仍由 R7 检验。

## R5-02 默认工具

一个默认通用助手，先加载少量常用工具，其他已允许工具通过 search_tools 发现并加入下一轮。权限仍由当前 authentic capability snapshot 和原执行链判定；发现不能扩大权限。后移 Media、Worker、多 Agent、调度等默认能力。通过真实 Agent 与可控模型服务检查发现后调用、未发现工具处理、重启/下一任务重新收敛；记录协议数量与体积。真实选择错误、耗时、费用比较等可用配置后使用同一五项任务完成。
