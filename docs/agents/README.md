# RainyDays：Codex 专用研发手册

日期：2026-10-18。规划依据：源码 `417039e`、本机 Lux Desktop v0.1.898、已批准的四类工作方向及既有 R1–R7 路线。用户已确认“Lux Neo”就是这个本机版本。

**目标：同事安装后，能自己配置模型、完成常见工作、检查成果、继续修改，并在出错时知道如何恢复。** 这是限定支持范围的成熟桌面产品；不承诺任意网站、任意文件、任意模型和任意任务都能成功。

本手册是可执行的研发约束与验收方案，不是成功保证。模型质量、提供方可用性、安装环境和真实用户试用都需要实际证据。新增规格和 D 系列任务为 proposed；本轮已获完整规划授权，先交付可审阅的全套任务，未把新增代码工作视为已经验收。原 R1–R5 的批准和证据继续有效。

## 一、先知道做到哪里算交付

| 状态 | 必须达到 | 可向谁提供 |
|---|---|---|
| 工程可运行（当前） | 源码流程和部分自动测试通过；真实模型、当前安装包仍有缺口 | 开发者 |
| 同事试用版 Beta | 固定任务 ≥34/40、每类 ≥8/10；安装、数据恢复、停止、首次配置通过；无阻塞故障 | 明确参与试用的 3 位同事 |
| 稳定同事版 1.0 | 同一候选固定任务 ≥38/40、每类 ≥9/10；3 人一周 ≥30 次真实任务、≥90% 无开发者救场完成；升级/恢复有证据 | 支持范围内的熟悉同事 |
| 更广分发 | 支持能力、签名/渠道、规模和平台另定 | 不在本计划承诺内 |

计分、故障分级、时间指标与证据规则统一见 [验收手册](acceptance.md)，不得通过重命名“完成”绕过门槛。

## 二、每次会话的阅读顺序

1. [STATUS](../STATUS.md)：当前分支、已验证事实、阻塞与下一步。
2. [同事版规格](../specs/colleague-delivery.md)：用户应得到什么。
3. [任务索引](../work/colleague-delivery/plan.md)：选择第一个已批准、未完成、依赖已满足的任务。
4. 仅加载该票据的研究、代码、测试；按 [workflow](workflow.md) 实施。
5. 到发布阶段才加载 [发布与维护](release.md)；给同事的说明在 [使用指南](../user-guide.md)。

按任务读取：[架构与代码入口](architecture.md)、[安全投入边界](safety-budget.md)、[Lux 逆向研究计划](../research/lux-reference-plan.md)。无需每次通读全部历史 parity 报告。

## 三、当前判断

现有内核值得复用。此前 26 项产品回归、15 项 UI/IPC、两个演示启动入口已通过，文档输入/产出和来源链有工程证据；这些成绩来自既有记录，本次规划没有重跑。真实研究五项因额度失败，不能证明 Agent 的真实质量。旧工作台超时、文件根 400 和一次后台意外退出仍需定位。

当前最需要补齐：稳定启动及旧数据路径、模型与上下文质量、可靠完成/停止、工作目录体验、可用成果、重复任务、安装升级和真实用户反馈。完整重写内核或完整复刻 Lux 都缺乏收益证据。

## 四、第一条给新 Codex 的指令

> 阅读 AGENTS.md 和 docs/STATUS.md。按照 docs/work/colleague-delivery/plan.md，从第一个未完成且依赖满足的已批准任务开始。先报告证据和拟修改边界，再实现该任务及必要验证，更新票据与 STATUS。复用既有运行链；Prism、钉钉与冻结能力保持范围外。遇到模型额度或外部环境阻塞，记录事实并推进不依赖它的任务；不得把未执行的验收标绿。

首次批准整套计划后将新规格与可执行票据状态改为 approved/ready，并按依赖连续推进。涉及新付费测试、对外发送或扩大产品范围时才补充必要决定；已经给出的授权无需重复索取。

## 五、投入与停止规则

- 一次推进一个主要产品切片；同时最多一个必要故障修复。先做能演示的最短完整流程。
- 预计 26–45 个维护者工作日，另需一周同事试用窗口；按一名熟悉项目的维护者持续配合 Codex 估计，约 6–10 周量级，非工期承诺。D01/D02 完成后重估。
- Lux 研究首轮最多 3–5 人日，分散在对应任务开始前；没有待回答问题就停止。
- 新安全/治理框架计划投入上限 10–15%；已有真实数据损坏、泄露、任意执行故障必须修复，超额应收缩功能范围。具体执行见安全预算。
- 两个周度检查点都没有新增可演示用户结果时，停止扩张，检查是否被模型、原生打包或治理拖住；用一个有边界的替代实验作决定，不能无限补底座。
