# 桌面界面深度优化

## 方向与范围

用户要求继续接近 Claude Code 的平衡感，明确整体比例与组件细节同样重要。沿用已确认的 A 构图、暖瓷画布、暖灰侧栏、墨色正文和克制陶土色，保留会话、附件、文档成果、文件预览、终端、任务状态和设置的行为。本轮不更新 impeccable 技能。

## 已实现

- 侧栏 240px（980px 以下为 216px），标题栏 56px，阅读列与输入区共用 760px 上限；720px 以下改为会话抽屉。桌面可收起侧栏。
- 输入区分为书写区与工具栏，加入实际模型配置入口、助手模式选择和运行停止控件。输入自动增高，清空后恢复 43px。
- 成果行统一文档图标、文件名、格式说明与操作；执行记录默认折叠，可检查参数、状态和结果。
- 所有产品控件图标使用同一 SVG 符号集，覆盖静态界面以及动态会话、工作台、附件、文件、工具记录、任务和后台任务。
- 空白对话提供三个填写草稿的示例；点击不自动启动任务。更多菜单支持点击外部和 Escape 关闭。设置和文件预览沿用同一控件密度。
- 修正原输入高度计算产生的额外空白，增强选中行的辅助文字对比度，补齐 Markdown 文件预览的标题、段落和列表样式。

## 设计复核

独立复核最终结论为 **ship**。A 的视觉身份与主构图保持一致，新的整体比例和两行输入区属于本次获授权深化。复核提出的唯一材料性问题——窄屏抽屉的键盘/可见状态——已修复并确认：关闭侧栏 inert，打开背景 inert，焦点进入并双向循环，Escape/外部点击/会话选择统一关闭，嵌套设置与窗口宽度变化正确恢复，展开状态同步。更新截图等待抽屉位置稳定后捕获。
