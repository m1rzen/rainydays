# R4 审查

2026-09-30；起点 df00807。Standards 与 Spec 分别检查，无委派。

## Standards

复用有界网络读取、重定向网关、消息数据库、文档路径许可与 UI SVG。新模块仅投影宿主回执；正文、搜索摘要与 assistant 声称无法创建已读来源。来源文字用 textContent，未增加 HTML 执行、外部打开或 IPC 权限。Word references 先核对当前会话已读最终 URL，再预留新文件。取消与原子提交链未改变。marked 与 docx 均为已有依赖。

## Spec

实际 HTTP → Agent → 来源历史 → 可编辑 Word 流程通过，包含重定向、失败、正文 Source 伪造、未知链接及重开恢复。极短读取也通过布尔 partial 明确告知截取。桌面验证 4 个来源状态、报告成果、未读链接提醒、默认折叠、无障碍和 360px 无溢出；重启不重新取网页。运行当前 DuckDuckGo 查询实际得到三个 Electron 官方结果。

审查发现：手写链接正则漏掉 GFM 自动链接与参考式链接。先红后改为与 renderer 相同 marked 解析，代码片段排除。首次会话恢复会清掉正在显示的回答也在实际桌面复现，发送时递增已有 selection generation，失效旧恢复；新测试要求回答正文仍在 DOM。

## 限制

来源读取一致性不验证事实正确性。Word sources 参数受到验证，模型自行写入普通正文的假断言仍需真实质量验收。历史纯文本回执不回填。研究 prompt 会增加少量请求体积，默认工具仍由 R5 收敛。用户已批准 default 的五项真实验收，执行与判断完成前不计 R4 产品完成。

最终确定性 Word 测试另用 mammoth 检查参考资料实际 hyperlink，3/3 通过。最终桌面用例通过（约 75 秒，包含获取、文件授权、生成、重启）；不能将这项结果宣称为真实研究速度。独立真实任务运行器只保留批准的加密凭据，不访问原会话，也不放宽 IPC 或文件权限。
