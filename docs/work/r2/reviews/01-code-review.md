# R2-01 评审

起点 ed6afd2。分别进行 Standards 与 Spec 检查，未委派代理。

## Standards

- 附件句柄读取发生在远程 Worker 路由前，只查询当前调用会话已绑定的附件。真实 Agent/Broker 调度与跨会话拒绝已验证。
- 文档使用现有隔离解析 worker、取消与资源归属；未新增执行通道。附件存储延迟导入，普通文件读取不因新增模块额外初始化数据库。
- SQL 11→12 在现有迁移事务中重建附件 MIME 约束、复制所有列并重建索引与触发器；旧绑定消息、附件字节与重启一致性已验证。发布元数据及打包校验同步更新。
- 页面最多 12 个提取行，每行最多 500 个 Unicode 字符；下一页位置稳定。原始字节和哈希保持不变。分页每次重新解析，暂未缓存，属于已知性能限制。

## Spec

- PDF/DOCX/XLSX 上传、索引投影、按段读取、末尾取回、会话恢复、损坏内容与空文本 PDF 提示有定向测试。
- 真实 Electron 验证 PDF 文件选择器上传与原始字节取回；Office 创建工具的输出再次解析及修订稿回读通过。未把合成模型测试当作真实答案质量证明。
- 保留已有 Office 提取文本预览；本轮没有重写版式编辑，也没有取消逐次写入确认。
