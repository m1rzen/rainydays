# R2-02 Code review

日期：2026-09-28。基点：7de041f；范围为 R2-02 的暂存差异，排除原有 WIP。Standards 与 Spec 分开顺序审查，未使用子代理。

## Standards

- 审查 Agent 审批、Broker 上下文/注册绑定、PathPolicy 预检与原子提交、文档回执、会话 API 与界面。沿用 TypeScript、现有 ESLint 和公共接口测试；无新增依赖或数据库迁移。
- 新建许可绑定真实根运行对象；仅内置 Word/Excel，子任务不能继承审批工具。生成精确一次性 grant，根集合收窄为 OUTPUT_DIR，操作集合只保留原策略中的 create-file。取消/退役通过原生命周期撤销；不恢复到新一轮或重启。
- 预检与提交之间存在竞争窗口：执行网关再次预检并拒绝已有目标；提交使用已有缺失目标身份与原子创建约束。分别测试预检前、预检后文件出现，原字节保持不变。替换网关不在范围许可内。
- 成果列表只接受成功、未截断、与内置文档工具调用配对的回执；界面使用 textContent 与 DOM 控件，不把文件名拼进 HTML。打开仍由 File Viewer 验证当前目录权限和文件存在。
- 已修复：检查截图发现工作台根面板未限制高度，成果标题/输入框会被内容挤出可见范围；补足高度与长路径换行。
- 已修复：后台等待根目录后发起的新刷新、以及较早发起的目录响应，都可能清空用户刚打开的预览。后台刷新与目录响应分别检查现有代次，增加确定性的延迟响应回归。

## Spec

- 一次范围确认生成 Word/Excel、覆盖拒绝、下一轮重新确认、另存修改版和原件字节不变已由产品测试覆盖。
- 独立的 Broker 行为测试覆盖越界、其他工具、子任务、替换、竞争写入、结束撤销与下一轮隔离。
- 真实 Electron + 本机确定性模型服务覆盖上传 PDF、附件阅读、生成两份文件、重启恢复、预览和继续修改；模型质量不属于该夹具可证明的范围。
- 旧纯文本回执不追溯为成果；新成果清单随消息清空/删除/回滚而移除，文件本身仍保留。首版入口只收集内置 Word/Excel，其他输出类型后续按任务扩展。
