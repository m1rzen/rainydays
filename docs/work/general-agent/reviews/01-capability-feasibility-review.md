# A01 原型与规格审查

日期：2026-10-18。范围为A01票据、prototype.md、四个实验源文件及其向A03/A05/A07/A08/A09的研究交接。Standards和Spec两轴顺序核对，未委派。

## Standards

原型使用临时配置/项目、本地MCP、独立headless浏览器及自建离屏窗口。没有日常凭据、模型调用、生产注册/配置或权限修改。CLI通过真实Broker/native链，拒绝结果原样记录；没有无约束回退。SDK依赖、.NET输出与截图在忽略目录，CLI临时目录删除前检查父目录和前缀，源代码明确throwaway。

原型未包含生产级认证/超时/多服务生命周期，不允许直接复制为产品。Windows仅语义控件操作及自身窗口截图，不证明任意窗口/焦点和多显示器。未发现阻塞性标准问题。

## Spec

五项均有实际输入与结果：Node/Python/项目导入失败、MCP两传输成功、浏览器键盘缺陷、图片角色缺口、非管理员Windows操作和可独立发布。失败有明确后续任务与最小实验；没有把局部成功当产品完成。接入契约、支持矩阵、体积/依赖与成本重估齐备。

真实视觉、干净机器和完整项目CLI仍是后续验收，不在本票冒充通过。A01完成表示完成调查，可进入后续实施；其产品能力必须在各票验证。无阻塞性规格发现。
