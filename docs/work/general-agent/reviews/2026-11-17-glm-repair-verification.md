## Spec review

结构化检查点复用 entities 存储，包含会话/原始运行归属、任务原文、Node/平台/模型/人格标识、已观察或登记的输入与产物版本、已保存标题边界、完成写入指纹、任务状态和下一步。每个成功工具回合保存已核对边界；恢复前重新授权并校验版本，版本变化时停止自动续写。同一已提交写入的重复参数在续接时被宿主阻止。

真实进程重启、进程突然终止、取消后续接及输入变化均有隔离 HTTP 回放。已保存标题证明文件中的章节边界，不代表模型的事实质量已评分；任意脚本的隐式输入输出仍须通过 read 或 register_output 显式进入可校验范围。已截断片段不补接执行，已执行的写入不自动重放。

语义样本补充六组固定合成原材料与任务要求，24 条原标注由 Codex 独立对照材料核对并绑定 sourceCaseId；保留待人工审核标识。样本结构检查与实际文稿的事实/语言/版式质量评分分开。模板不再把无依据推断放进“待确认”，也不对所有纪要要求最低页数。
