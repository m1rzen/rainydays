## 验收条件

- [ ] S01/S02的加载/作用域/开关行为通过；相关技能在普通任务中产生可核对成果。
- [ ] 根/子目录说明按实际文件范围适用；无关资料里的指令不授予额外目录、密钥或外发权限。

- [ ] 已有技能和旧会话兼容；不自动执行技能内安装脚本。
