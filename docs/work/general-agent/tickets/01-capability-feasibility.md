## 用户结果与工作范围

先用2–3日验证关键接入，不做新的通用框架。使用临时JS/Python项目、本地MCP测试服务器、浏览器测试页和无敏感内容的Windows测试窗口。记录五项：现有隔离执行器能否运行构建/测试；MCP真实列举/调用；浏览器真实输入；标准用户窗口观察/输入及打包选型；工具图片能否投影到模型请求。确认默认助手的允许列表、注册、发现与可用状态如何接通。

## 先读与研究

src/tools/shell.ts、terminal-tools.ts、task-tools.ts、settings-schema.ts、version.ts、browser.ts、llm.ts；Lux help/tools.md与win-desktop.ps1只定向参考。模型桩用于工程图片投影，不作为视觉正确性证据。

共同实现原则见[能力手册](../../../agents/general-agent-capabilities.md)。实施前查当前定义与官方资料，记录实际版本；不要凭旧文档猜接口。

## 验收条件

- [ ] 五项探针都有输入、实际结果和已知限制；失败有具体下一实验/替代，不能笼统写可行。
- [ ] 写明默认助手如何调用各能力；不依赖手工换Persona或绕过工具允许列表。
- [ ] 桌面helper的打包方案与普通用户限制有实验证据；若无干净环境则标未测，A09补验证。
- [ ] 给出最小接口决定、支持矩阵草案、成本重估；研究不超过期限后自动扩成完整Lux逆向。
- [ ] 无模型额度时只验证请求图片结构，真实视觉未知移交A08；不调用现有未授权密钥。

## 验证接口与证据

临时项目实际进程/退出码、真实loopback MCP请求、本地浏览器与测试窗口观察；只在忽略目录保存原始实验输出。

计分与真实模型授权见[通用验收](../../../agents/general-agent-acceptance.md)。工程桩与真实结果分别记录；没有实际执行的条件不能勾选。

## 范围与回退

本票完成意味着风险得到可审阅结论，不意味着五种能力已产品化。即使某探针失败，也要有能继续实施的具体方案；若无可行方案保持blocked，不批准依赖该方案的实现。

保留他人修改和用户数据；变更按本票独立提交，回退仅针对自身变更。涉及数据迁移先准备测试副本与恢复路径。复用[安全预算](../../../agents/safety-budget.md)，只加本能力需要的边界检查。
