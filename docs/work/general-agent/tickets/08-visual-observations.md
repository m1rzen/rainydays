# A08 工具图像进入视觉模型

Kind: implementation

Status: proposed

Spec: [通用Agent规格](../../../specs/general-agent.md)

Blockers: A01、D02、D03

User stories: G07、G10

## 用户结果与工作范围

将浏览器/桌面/MCP工具图片接入LLM图片消息。保留tool call与观察关联、目标、时刻、图像尺寸和缩放；控制图片数量/分辨率/上下文预算，保证坐标转换。记录模型视觉能力并提供缺失时的明确状态。先用合成非敏感图测试，再认证真实模型。

## 先读与研究

src/llm.ts、tools/image-helper.ts与工具结果投影；D02模型契约、D03预算。不能只把PNG路径拼进文本提示。

共同实现原则见[能力手册](../../../agents/general-agent-capabilities.md)。实施前查当前定义与官方资料，记录实际版本；不要凭旧文档猜接口。

## 验收条件

- [ ] 模型请求确实含图片数据/可用图片引用，而非只有本机路径；call关联和重放历史语义正确。
- [ ] 真实视觉模型识别随机生成测试图中的目标及位置，证据无预置答案泄漏；坐标经缩放后正确。
- [ ] 不支持图像/载荷过大时清楚报错或采用已认证视觉配置，不静默装作看见。
- [ ] 预算包含图像，长会话保留必要观察引用；截图不无限常驻或进入普通日志。
- [ ] 缺模型授权时工程可先完成，但本票不得verified；真实识别和M04视觉结果必须补齐。

## 验证接口与证据

真实LLM请求投影检查、合成随机图、已授权视觉配置实际识别与坐标回算；不是仅mock答案。
