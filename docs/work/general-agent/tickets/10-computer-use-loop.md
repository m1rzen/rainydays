User stories: G06、G07、G10

## 用户结果与工作范围

把浏览器和桌面观察/动作接到同一Agent循环：选择目标→观察→动作→等待→新观察→结果验证。优先稳定语义控件，必要时视觉。显示控制目标/进展，允许暂停、用户接管与停止。恢复须重取状态，不重放旧坐标。动作/时长/无进展次数有上限，任务内按既有授权连续执行。

## 先读与研究

能力手册的GUI观察合同、图像投影和控制循环；现有run取消/等待用户状态与按需面板。

共同实现原则见[能力手册](../../../agents/general-agent-capabilities.md)。实施前查当前定义与官方资料，记录实际版本；不要凭旧文档猜接口。

## 验收条件

- [ ] B05、W01–W05通过真实模型和实际驱动完成；W03在明确版本WPS或Office执行。
- [ ] 至少一项无法仅靠DOM/UIA完成的场景经真实视觉动作成功，截图路径不算观察完成。
- [ ] 动作后有新观察或独立结果核对；点击响应成功不能直接宣布任务完成。
- [ ] 暂停/取消≤1秒反馈并阻止排队输入；接管恢复重新观察，失焦不串窗。
- [ ] 默认50动作/10分钟/3次无进展有限退出；登录/受保护界面有清楚接管流程。
- [ ] 无需用户切换Persona串接浏览器和桌面；已有对话与成果UI比例保持。

## 验证接口与证据

普通默认助手真实GUI任务，动作日志与观察、文件/DOM/UIA结果核验；暂停/取消/失焦/恢复的确定性故障注入。

计分与真实模型授权见[通用验收](../../../agents/general-agent-acceptance.md)。工程桩与真实结果分别记录；没有实际执行的条件不能勾选。

## 范围与回退

不开发无人值守全桌面自治。界面登录/发送等动作沿用用户实际授权，不对每次普通点击重复审批。

保留他人修改和用户数据；变更按本票独立提交，回退仅针对自身变更。涉及数据迁移先准备测试副本与恢复路径。复用[安全预算](../../../agents/safety-budget.md)，只加本能力需要的边界检查。
