## 用户结果与工作范围

独立实现薄Windows helper，复用公共UI Automation/Win32接口。提供列窗口、控件观察、截图、目标窗口动作、中文输入/快捷键/滚动/必要拖动。应用内标示目标与停止入口，普通用户运行且随包分发；不依赖同事安装开发SDK。根据A01选型，不复制Lux helper。

## 先读与研究

A01已在非管理员进程中验证UIA输入/Invoke和PrintWindow，并实际发布176.7MB的self-contained helper。见[原型记录](../prototype.md)：该体积需与系统薄宿主比较后再选；96DPI自建窗口成功不代表Office/WPS、焦点、缩放与多显示器通过。

Windows UIA/SendInput官方资料；现有工具/执行适配器、Electron打包与资源生命周期。目标窗口外操作与AppContainer不是同一边界。

共同实现原则见[能力手册](../../../agents/general-agent-capabilities.md)。实施前查当前定义与官方资料，记录实际版本；不要凭旧文档猜接口。

## 验收条件

- [ ] 在当前安装候选中，记事本输入/保存及资源管理器定位的驱动路径真实通过。
- [ ] 125%/150%DPI、多显示器移动/缩放后坐标重算；窗口句柄/PID/前台变化能检测。
- [ ] 失焦暂停全局输入；修饰键释放、Unicode输入与剪贴板临时使用不破坏用户状态。
- [ ] UAC/高权限或不可观察窗口明确交用户；不得自动提权或宣称能绝对隔离全局输入。
- [ ] helper以标准用户交互会话运行，经现有宿主认证接收有限UI动作；不因GUI需要放开普通CLI隔离或增加任意shell执行接口。
- [ ] 停止/退出后没有helper孤儿进程和排队新输入；不关闭用户原有应用。

## 验证接口与证据

标准用户真实测试窗口、原生安装包、焦点切换与DPI矩阵；W01/W02/W04/W05驱动部分，结果文件可只读核验。
