## 用户结果与工作范围

优先修好现有CDP后端，从默认助手进入。管理本任务拥有的浏览器/标签，提供新鲜DOM/可访问性观察、真实点击/键盘、页面等待、标签导航、上传与下载完成。登录交给用户，恢复重取观察。发现已有合成事件不足时只替换相应操作；保持一个后端。

## 先读与研究

A01实测当前press Enter不会提交原生表单、Tab不会移动焦点，虽然旧CDP流程通过。按[原型记录](../prototype.md)用真实输入修复并验证，不能靠element事件调用成功判定。

src/browser.ts、tools/browser-tools.ts、eco08-browser-session/cdp测试。评估当前element.click和合成KeyboardEvent的局限；截图语义接A08/A10。

共同实现原则见[能力手册](../../../agents/general-agent-capabilities.md)。实施前查当前定义与官方资料，记录实际版本；不要凭旧文档猜接口。

## 验收条件

- [ ] B01–B04工程路径在真实浏览器通过；Enter/Tab实际提交与焦点正确。
- [ ] 节点重建/导航后旧引用被识别并重取，不错误点击其他标签。
- [ ] 上传范围和实际下载文件可核对；登录暂停/恢复不绕过验证。
- [ ] 用户其他标签/原浏览器不被任务退出误关；取消后不排队新动作。
- [ ] 普通会话入口与受支持浏览器/连接方式可理解，不要求用户手工调内部RPC。

## 验证接口与证据

真实本地SPA/上传下载/多标签页面、实际浏览器会话；CDP组件回归与用户入口。
