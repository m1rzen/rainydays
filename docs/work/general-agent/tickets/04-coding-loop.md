两个实际缺陷先red：JS项目已修改三次，第四次同命令检查被旧通用重复计数拦住；无修改重复失败在工具拒绝后仍继续请求模型，直到总迭代上限。改为仅在edit_files成功且宿主回执表明字节版本确有变化后重置命令重复计数；读取计数和256种调用上限保留。loop检查移到执行前，允许同一串行批中的“编辑→检查”看到前面的实际写入。无变化的编辑不能重置计数。

每run记录仍失败的检查及后续真实修正批次；默认最多三次。第三次修正后同检查仍失败，或重复调用触发旧loop拒绝时，保存真实工具回执并明确停止、可回复继续；同批尚未执行的工具也拒绝。检查成功结束该轮修正计数。提示词要求从项目约定选检查、区分环境失败并按实际结果交付，不修改测试骗过检查。

20题预评测准备见[评测说明](../evaluations/04-coding.md)。生成器只创建新的临时项目，参考实现放在项目根外；没有模型/凭据读取或自动调用。10个JS、10个Python项目均有真实检查、用户未提交注释与未跟踪笔记；原始实现均失败、独立参考副本均通过。该结果只认证样例可运行，模型分数仍为未运行。
