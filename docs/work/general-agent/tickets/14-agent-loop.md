# A14 长任务Agent循环

Kind: implementation

Status: ready

Spec: [通用Agent规格](../../../specs/general-agent.md#7-2026-10-20路线修订开发模式与agent循环)

Blockers: 无

User stories: G04、G10

## 用户结果与工作范围

默认助手能像通用编码Agent一样完成几十到上百步的任务：迭代上限可配置且默认足够长；有可见的任务计划并随进展更新；用户在运行中追加的话进入下一轮而不是等任务结束；常用开发工具不必每次先search_tools发现。仍复用现有Agent/Session/工具管道，不新建第二个循环。

## 验收条件

- [ ] 迭代上限从固定25改为配置项，默认≥100、上限可调；达到上限时如实说明未完成部分，不伪装完成。
- [ ] 计划工具：模型写入/更新步骤及状态，界面按需展示；计划只是进度投影，不授予权限。
- [ ] 运行中用户追加消息进入下一轮模型请求，停止仍立即生效；不重放已执行的写入。
- [ ] 开发模式开启时，读写/命令核心工具首轮即可用；关闭时保持原按需发现与允许列表。
- [ ] 产品回归、相关Electron用例通过；真实模型长任务表现留A04/A13。

## 范围与回退

不改模型协议、不建多Agent编排。按本票独立提交，回退只针对自身提交。
