# D16 三位同事独立使用一周

Kind: implementation

Status: proposed

Spec: [同事版交付规格](../../../specs/colleague-delivery.md)

Research: [技术资料：同事版研发](../../../research/technology-stack.md#同事版研发2026-10-18)

Blockers: [D15](./15-beta-evaluation.md)

User stories: U01–U12

## 用户结果与工作范围

1. 由维护者安排三位同事和至少两套干净环境，提供包、说明与支持范围；不擅自发送邀请。
2. 每位使用五个工作日、至少八次任务，总计至少三十次且四类各至少五次。
3. 观察首次使用，不代操作；记录真实卡点、救场与用户自己的反馈。

docs/agents/release.md、docs/user-guide.md、Beta 候选与反馈记录。

与 Lux 有直接对应且尚未解决的问题，按 [有界研究计划](../../../research/lux-reference-plan.md) 只研究本票需要的行为。已有材料足够就直接记录复用决定。外部库/API 有变化时读已安装定义与官方资料，不凭记忆更换技术栈。

## 验收条件

- [ ] 三人首次配置和首个任务的耗时、帮助次数都有记录。
- [ ] 试用任务逐项有结果和失败原因，统计独立完成率；低于 90% 的事实保留并移交 D17，不能改写分母或删除失败。
- [ ] 试用记录收齐不等于稳定版通过，失败交给 D17；发现 P0/P1 暂停该候选。
- [ ] 无法安排用户时标外部 blocked，作者自测不能替代。

## 验证接口与证据

人工试用记录；用户同意分享的脱敏信息与版本号，不收集不必要的原文。
通用计分与证据口径见 [acceptance](../../../agents/acceptance.md)。本票通过需要所有验收条件有实际证据；未测部分明示，不能以旧报告代替。

## 范围与回退

不构造用户证言、不代填满意度；不开发遥测系统代替观察。
保留其他人的改动。数据结构变化先保存可恢复测试快照并明确兼容；代码按本票独立提交，回退只针对该提交，不能重置他人工作。
