## 用户结果与工作范围

1. 限定已选目录内改名/移动，先给逐项预览、目标冲突和数量；用户确认后执行计划。
2. 逐项保存结果，区分未执行/成功/失败；取消保留真实完成清单。
3. 撤回只反转仍匹配本次操作后状态的项目，外部改动提示冲突。

## 验收条件

- [ ] 12 个文件含 2 个重名冲突的 O05 完整演示；冲突不覆盖，原内容不丢。
- [ ] 执行中取消，完成数量与磁盘一致；只撤回已完成项。
- [ ] 执行前目标被外部创建、撤回前文件被外改，两种竞态均不覆盖他人内容。
- [ ] 计划变更或越出批准范围需要重新确认。

## 验证接口与证据

真实临时目录 + 公共文件接口的状态检查，Electron 预览/批准/撤回一条流程。
通用计分与证据口径见 [acceptance](../../../agents/acceptance.md)。本票通过需要所有验收条件有实际证据；未测部分明示，不能以旧报告代替。

## 范围与回退

不做自动永久删除、跨盘原子事务、全磁盘索引或完整回收站服务。
保留其他人的改动。数据结构变化先保存可恢复测试快照并明确兼容；代码按本票独立提交，回退只针对该提交，不能重置他人工作。
