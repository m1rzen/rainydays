状态：verified。授权：已批准路线、用户 2026-09-30 顺序开发指令。

规范：[R3](../specs/R3-development-baseline.md)。研究：[技术依据](../research/technology-stack.md)。起点：bf3a7e4；既有 WIP 已单独保存，见基线记录。

## 接口与验收

- npm `check:product`：typecheck、lint、源码产品测试、界面和 IPC 核心测试；无需治理清单重生成。普通反馈实测不超过两分钟，记录机器与构建前提。
- npm `test:product:desktop`：先构建，再临时用户目录测试源码桌面启动、R1 断流及 R2 文档上传/产出/恢复。
- 实际 Electron DOM 检查输入高度随内容增长/收回、150px 上限、无 style 属性、窄窗口仍能输入。
- 不改变鉴权、CSP、执行权限、数据目录或已批准 UI。
- 分别记录源码检查和安装候选门槛；冻结能力继续标为未验收。

新增命令只是可逆串联，不添加镜像脚本测试；通过实际运行验证。输入行为使用真实桌面先红后绿，静态 CSP 原约束保留。

## 验证

`check:product` 23.01 秒，产品 17/17、UI/IPC 15/15，类型与 lint 通过。桌面命令首次暴露旧 R1 定位问题，其余 3 项通过；修复定位后 R1 独立复验通过；最终源码桌面与 360px 输入测试通过。见 [审查](../work/r3/reviews/01-code-review.md)、[诊断](../work/r3/diagnostics/01-desktop-feedback.md)。安装候选与真实模型仍由后续阶段验收。
