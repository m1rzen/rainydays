# R5-02 默认通用助手与按需工具

状态：verified（工程），2026-09-30。起点 68ecfc7；依赖 R2 已 verified、R5-01 工程 verified。规范：[R5](../specs/R5-first-use.md)。用户已授权顺序实施，配置额度未恢复不阻止确定性工程。

接口：TaskToolSelection 接收当前 authentic snapshot 的协议，仅对具备 search_tools 的 general 助手启用；首轮十二个常用文件/研究/文档工具，发现结果把其他允许工具加入下一轮。宿主成功 search_tools 回执提供工具名；不从普通网页或模型正文加载。发现前直接猜测工具返回可操作错误，其他 Persona 保留既有完整工具。

默认 Persona 收敛文件、研究、文档、记忆、下载、任务拆分与受保护数据脚本；Media/Worker/浏览器控制/多 Agent/调度退出默认工具允许列表。现有权限网关、执行隔离及高级 Persona 不改变。任务结束或重开后按需加载状态重新开始，不能增加父权限。

验收：真实 Agent 先发现后成功调用；猜测未加载工具不执行；回执不能加载父上下文外工具；失败/截取不加载；无发现的兼容 Persona 不改；下一任务重新收敛。记录真实协议数量与请求工具体积；真实模型错误率、耗时、费用等用户补充配置后对同一五项任务测量。

审查发现既有旧会话定义绑定会在默认工具变化后失效，原选择接口只返回错误，界面静默留在别的会话。纳入兼容性修复：返回明确的定义变化状态，旧历史只读可见；用户点击“使用新版助手继续”后复用现有 Fork 创建副本，不修改原绑定或继承旧任务许可。实际重启回归覆盖拒绝旧定义执行、保留历史和副本恢复。
