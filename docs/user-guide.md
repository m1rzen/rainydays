# RainyDays 同事使用指南

文档日期：2026-10-18。**此为随同事版研发维护的指南草案；当前尚无通过全部门槛的安装候选。** “保存任务”“批量整理”“应用内恢复”等入口仍待 D 系列实现，发布前必须用实际界面替换待实现标记。

## 安装与第一次使用

收到发布者提供的 Windows 安装包和版本说明后，按向导安装并从 RainyDays 快捷方式启动。不需要自己安装 Node 或打开 public/index.html。

在模型设置中填写发布者说明里支持的服务地址、模型名称和个人凭据。不要把密钥发送到群聊或反馈截图。保存后主动点击连接检测；检测可能产生一次很小的模型费用。额度、认证或网络失败时按界面提示修正。

选择本次资料位置与成果位置。没有部门共享盘也可以处理本地文件。应用在本机保存历史；发送任务时，相关内容可能传给所选模型服务及必要的搜索服务，请使用适合该服务处理的资料。

输入框下方显示当前资料与成果文件夹，点击可进入设置更改，也可以在设置中用“选择”按钮选目录。更改位置不会搬动原文件。高级偏好中的“公司资料源”默认关闭；升级后原部门路径保留，需要时自行启用，只读接入。网络盘离线、目录被删除或没有权限时，检查提示并重新选择可用目录即可，无需修改配置文件。

## 四类工作示例

**读文件：** 添加 PDF、Word、Excel 或文本，输入：“请比较这两份文件的日期、金额与责任人，标注依据位置；有冲突请列出来。” 文本型文件是首批支持范围；扫描件或损坏文件应提示限制。

**做研究：** “研究这个问题，阅读多个公开来源，区分事实和推断，给出引用及一份 Word 简报。” 搜索结果不等于全文已读，可打开来源清单检查读取状态。

**产出与修改：** “依据这些资料，在选定成果目录生成 Word 报告和 Excel 汇总表。” 同一次任务内批准新建范围后可连续产出；下一次发送修改要求会重新确认范围。成果默认另存，打开文件后核对内容与排版。

**重复工作〔待 D10/D11〕：** 在成功任务上选择“保存任务”，确认可替换的输入和输出规则。下次换资料后手动运行；新任务不会沿用旧授权。首版不会在应用关闭时自动按时执行。

批量改名/移动〔待 D09〕须先看预览和冲突，再执行；撤回遇到外部修改会提示，不能把撤回当成任意文件备份。

## 通用任务示例〔新增能力待A系列实现〕

以下是规划中的使用方式，不能据此认为当前版本已经有这些入口；发布前用安装候选逐条核对。

- **改代码与测试：** 选择项目目录，提出“修复这个问题，保留我已有的修改，运行项目测试并展示差异”。项目需要的Git、语言运行时等按界面提示准备；普通文件工作无需安装这些工具。
- **CLI：** “在这个目录运行数据转换，给出结果；执行失败请说明原因。” 可展开命令和输出、输入必要回应或停止。未执行的检查应明确显示。
- **MCP：** 在工具连接设置添加兼容本地或HTTP服务器，完成所需认证，再在对话使用。第三方服务器可能需要自己的运行时/账号；不要在聊天中粘贴密钥。
- **网页：** “把这个页面中的资料整理成表格。” 交互需要浏览器会话；登录或验证码由你接手，完成后继续。
- **Windows应用：** 选择目标窗口，“打开报告，把标题改成……并另存”。应用应显示控制目标；可随时暂停/接管。视觉路径需要支持图片的模型，受保护或提权窗口交给你操作。
- **技能与子任务：** 按需启用相关技能；复杂资料任务可展开查看有限子任务的进展。停止父任务应同时停止所属子任务。

## 理解状态和停止

任务会显示当前阶段、所用资料、已产生的文件与等待事项。可以停止正在执行的工作；停止不会删除已完成成果，也不能撤销已经完成的外部请求。

中断或重启后先看已有成果，再选择继续或另存重做。若旧对话提示助手定义已变，可查看历史并选择“使用新版助手继续”；原对话保留。

关闭窗口可能只是收至托盘；要完全结束应用，请使用菜单或托盘“退出”。

## 出错时

| 提示 | 先做什么 |
|---|---|
| 密钥/模型配置错误 | 对照发布说明检查模型和地址，重新保存并检测 |
| 额度不足/限流 | 检查所选服务账号；不要反复点击重试 |
| 文件/目录不可用 | 检查文件是否存在、网络盘是否连接，或改选本地目录 |
| 内容太长/不支持解析 | 缩小范围、分段读取或换文本型文件；不要假设全文已被理解 |
| 写入冲突/无权限 | 另选成果目录或另存文件，保留原文件 |
| 应用异常/历史不可见 | 记录版本与错误编号，先保留现有数据，再联系维护者 |

应用内备份/恢复的具体入口待 D14 验收后补齐。遇到故障不要自行复制旧数据库覆盖当前目录，避免丢掉新会话。

反馈时提供版本、做了什么、预期与实际结果；敏感正文与密钥无需提供。诊断导出入口若已在该版本支持，先预览内容再主动发给维护者。

## 支持范围与限制

完整版本面向Windows 11 x64，实际模型、文件类型、代码语言/CLI依赖、MCP服务器、浏览器和Windows应用版本以发布说明为准。当前尚未完成新增能力验收。复杂版式无损编辑、扫描OCR、任意网站/程序、无人值守执行、跨设备与全部Office格式未纳入承诺。Prism和钉钉不在本产品计划内。

模型可能回答错误；交付给他人前核对关键事实、数字与引用。应用应帮助定位依据并呈现失败，不能替代你对成果的判断。
