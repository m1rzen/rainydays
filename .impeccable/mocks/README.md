## 视觉方向

熟悉的文字助手界面，暖灰背景、炭黑正文、低饱和陶土橙仅用于主要动作和品牌标记。使用清晰无衬线中文字体，代码与执行记录可以使用等宽字。助手回复以自然排版呈现，用户消息用轻底色区分；统一细线图标替代 emoji。使用真实层级、留白与对齐建立质感，不放置宣传画、虚构指标或装饰性仪表盘。

用户指定参考优先于探索抽签（seed 02c2d474，原指向候选 7 雾中窗台）。此次不继续探索额外品牌世界。

## 三个构图方案

1. A 静谧工作间：窄会话侧栏，宽阔居中对话，底部输入框；成果以对话内紧凑条目呈现。推荐作为默认布局。
2. B 对话与成稿：同一视觉系统，左侧会话、中央对话、右侧按需打开的文档预览，展示完成后检查结果的状态。
3. C 专注画布：会话入口折叠成窄导航轨，主区域单列对话，成果收在输入框上方的横向成果条，空间更安静。
