Use case: ui-mockup. Create an exceptionally polished high-fidelity desktop application screen for RainyDays, a general AI desktop assistant for Chinese-speaking people who work with files, research, and Word/Excel documents. This is a functional application design, NOT a landing page, not a photo, no browser/device frame, no perspective. 1536x1024 landscape screen. Design direction explicitly chosen by user: quiet Claude Code / Claude desktop feel, conversational and text-first. Warm neutral porcelain background #F6F5F1, slightly darker sidebar #EEEDE8, near-black #2B2A27 text, subdued grey secondary text, restrained muted terracotta #B56649 accent. Clear crisp Chinese sans-serif UI typography, natural readable font sizes, generous but purposeful spacing, sophisticated alignment, understated 1px borders only where useful, modest rounded 10-14px input and message shapes. Assistant answers are unboxed flowing text; user request is a soft warm-grey compact bubble. Uniform delicate outline icons, no emoji, no purple, no glowing edges, no gradients, no decorative photography, no dashboard metrics. Real product title RainyDays with original simple four-stroke rain mark, not Claude logo. Show a working conversation with illustrative data, not an empty welcome screen. Exact main conversation title: “整理本周的研究资料”. User message: “帮我整理这份资料，生成一份简洁的研究报告和数据表。” attached file pill “研究资料.pdf”. Assistant body: “资料已整理，报告和数据表已生成。” followed by short readable lines about “核心结论”, “保留来源与关键数据”, “你可以打开检查，或继续提出修改要求。” Collapsed tool activity line: “已读取资料 · 已生成 2 份文件” with a small check icon. Artifacts named “研究报告.docx” and “研究数据.xlsx”, subtle file-type labels DOCX / XLSX, buttons “打开” and “继续修改”. Bottom composer placeholder “描述你想完成的事，或添加文件…” with attachment plus on left and terracotta square send-arrow button on right, small helper text “Enter 发送 · Shift + Enter 换行”. Calm model indicator “通用助手” and small “就绪”. All glyphs sharp and legible. Small unobtrusive footer “设计预览 · 演示数据”. No marketing slogans or fictional capabilities. Composition A — quiet conversational workspace. Full-height 224px left sidebar, rest main canvas. Sidebar: RainyDays wordmark top left, outlined “新建对话” button below; search icon and “搜索对话”; small “最近对话” label; selected “整理本周的研究资料”, then “会议纪要整理”, “文档格式调整”; bottom settings outline icon “设置”. Main header slim: current conversation title left, icon with “成果 2” and overflow menu on right. Main conversation content a centered column about 760px wide, with open breathing space above and below the short exchange. User request near top right of content, assistant answer below left with tiny rainmark. Two artifacts are clean compact horizontal rows integrated into the assistant answer, absolutely not giant cards. Composer anchored to bottom of same centered column with generous outside margins. The full viewport feels balanced, quiet, meticulously spaced, and usable. No permanently-open right panel. Clear layout hierarchy: conversation first, file results second, supporting chrome third.
